# Prompt Presets

아래 문구는 템플릿의 목적을 정의한다. 게임 사실은 템플릿에 하드코딩하지 않는다.

## next_action
목표: 현재 진행도와 남은 체크를 바탕으로 가장 효율적인 다음 행동 3~7개를 정한다.

추가 지침:
- 이미 완료한 것은 제외.
- 초기화/마감이 가까운 항목 우선.
- 선행조건 때문에 지금 불가능한 작업은 이유를 표시.
- 정확한 수량/시간 계산은 제공된 구조화 값 우선.

## content_onboarding
목표: 해당 콘텐츠를 처음 시작하는 사용자가 페이지와 제공 데이터만으로 진입 순서를 이해하도록 설명한다.

출력 권장:
1. 이걸 왜 하는지
2. 지금 시작 가능한지
3. 준비물
4. 최초 1회 순서
5. 반복 루틴
6. 흔한 실수
7. 다음 확장 단계

## project_optimizer
목표: 프로젝트의 남은 단계/재료/반복 수급처/리셋을 바탕으로 완료 시간을 줄이는 실행 순서를 만든다.

추가 지침:
- shortage를 재계산하지 말고 앱 계산값을 우선.
- choice box/희소 재료는 자연 수급 확인 후 쓰는 전략을 고려.
- 오늘/이번 주 마감 콘텐츠를 먼저 평가.

## weekly_review
목표: 현재 daily/weekly/event 상태를 시간 제한과 가치 기준으로 우선순위화한다.

출력 권장:
- 지금 반드시
- 이번 주 안에
- 여유되면
- 건너뛰어도 됨

## verify_latest
목표: OPEN_QUESTIONS_OR_CONFLICTS와 날짜 의존 claim만 최신 자료로 재검증한다.

추가 지침:
- KR 공식 업데이트/모험가 가이드를 최우선.
- 최근 공식 패치와 오래된 가이드가 충돌하면 최근 공식 패치 우선.
- 공식 자료로 부족할 때만 최근 커뮤니티를 보조 근거로 사용.
- 검증 결과를 `확정 / 변경됨 / 미확인 / 충돌`로 나눈다.
